About This Tool

A QR code is a small square pattern that stores information in a way a camera can scan and decode instantly, without anyone needing to type anything. Phones have been able to read them natively from the camera app for years, which is why they showed up on restaurant menus, parking meters, product packaging, and event tickets. The technology itself is decades old and completely free to use; the code format is an open standard, not something any single company owns.

Static QR codes versus dynamic QR codes

There are two very different ways a QR code generator can build your code, and the difference matters more than most people realize.

A static QR code encodes your actual content directly into the pattern of the code itself. If you make a QR code for a website address, the URL itself is baked into the black-and-white squares. Once it is generated, it never needs to talk to any server again. Print it, and it will still work in ten years, even if the company that generated it no longer exists.

A dynamic QR code instead encodes a short link that points back to the generator's own server, which then redirects the scanner to your real destination behind the scenes. This lets the company offer features like editing the destination after printing, or counting how many times it was scanned. The tradeoff is that the QR code now depends entirely on that company's server staying online and that company continuing to honor the link. Some services only keep these redirect links active on a free plan for a limited time, and expect you to pay to keep them working indefinitely, or to keep seeing scan analytics. A QR code that stops working after printing thousands of flyers is a real, commonly reported frustration.

This tool only builds static QR codes. There is no redirect server involved because there is no server involved at all. Whatever you enter is what gets encoded, permanently.

How to use this generator

  1. Choose what kind of content you want to encode: a website URL, plain text, an email address, a phone number, or Wi-Fi network details.
  2. Fill in the relevant field. For Wi-Fi, this includes the network name, password, and security type, so a phone camera can join the network just by scanning the code.
  3. Adjust the size, error-correction level, and colors if you like. Higher error correction lets the code still scan even if part of it is damaged or covered, at the cost of a slightly denser pattern.
  4. Click Generate, then Download PNG to save the image for printing or sharing.
