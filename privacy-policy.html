Privacy Policy

Last updated: July 2026

This page explains what happens to your data when you use the Static QR Code Generator, located at this domain. The short version: nothing leaves your browser.

No data collection

This site does not have a server-side backend, a database, or any form submission. Whatever you type into the QR code form (a URL, text, an email address, a phone number, or Wi-Fi details) is read directly by your browser and turned into a QR code image on your own device. Nothing you type is ever sent to us, stored by us, or seen by us, because there is no mechanism on this site that would allow that to happen.

No cookies, no accounts, no tracking

This site does not use cookies, does not require an account, and does not run any analytics or advertising scripts that track individual visitors. There is nothing to opt out of because nothing is being collected in the first place.

Third-party library

The page loads one external script, the open-source QRCode.js library, from a public content delivery network (cdnjs.cloudflare.com) in order to draw the QR code image in your browser. This is a standard file download similar to loading an image or a font, and it does not transmit the content you typed.

Hosting

This site is hosted on GitHub Pages. GitHub, as the hosting provider, may log standard web server access information (such as IP address and browser type) as part of normal infrastructure operation. This is outside of our control and is covered by GitHub's own privacy policy, not this one.

Changes to this policy

If this site ever changes to add analytics, ads, or any data collection in the future, this page will be updated to reflect that honestly.

Contact

Questions about this policy can be raised via the project's GitHub repository.
